→ 상세 분석: [`12-CCTV-영상-기반-화자판정.md`](12-CCTV-영상-기반-화자판정.md)

**법적 블로커 없음** — 회의실은 비공개 장소라 개인정보보호법 제25조(녹음 금지 포함)가
적용되지 않습니다. 단 참석자 동의와 최소 범위 촬영이 필요합니다.

**기술 성립** — Light-ASD가 AVA mAP 94.06%, 경량, 오픈소스.
단 AVA는 영화 데이터라 실환경 성능은 자체 측정이 필요합니다.

| 선택 | 얻는 것 | 잃는 것 |
|---|---|---|
| A만 (현행) | 화자 100%, GPU 여유, 법적 부담 최소 | **UX 마찰** — 매번 전원이 앱 실행 |
| **A + C 융합** ⭐ | UX 마찰 해소 + 교차검증 + 연구 주제 | 범위 증가, GPU 부하, 영상 법적 부담 |
| C만 | UX 최고 | 정확도 하락, 얼굴 등록 필요 |
| **C를 후순위 확장** | MVP 안전 | 당장은 UX 마찰 유지 |

⚠️ **대학생 팀플의 진짜 문제**: 회의 장소가 고정되지 않습니다(카페·스터디룸·집).
고정 CCTV는 못 씁니다. **노트북 웹캠이나 폰 한 대를 카메라로** 쓰는 형태여야 합니다.
그러면 제25조의2(이동형)가 적용되고, 비용도 0원입니다.
