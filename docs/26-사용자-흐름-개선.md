# 사용자 흐름과 검토 결함 수정

2026-11-03. 검토 기준은 d1d706c이며 코드 변경·검증 결과를 이 문서에 남깁니다.
이 문서는 초기 검토·수정 시점의 기록입니다. 당시에는 실제 사용자 DB·녹음·인증
정보를 변경하지 않고 임시 DB와 합성 음성으로 검사했습니다.
후속 운영 반영·실제 모델 검증은 [실환경 검증과 릴리스](27-실환경-검증-및-릴리스.md)를 참고하세요.

## 수정 순서

1. 신원과 동의: 임의 이메일 로그인 차단, Google state/신규 가입 수정,
   초대 없는 프로젝트 참가와 다른 사람의 동의 변경 방지.
2. 회의 기록과 복구: 연속 녹음 디코딩, 동시 업로드, 실제 디코딩 기준 품질,
   작업 실패 후 재시도, GitHub 상세 수집 재시도, 암호화 설정 통합.
3. 사용자 화면: 기존 실제 통화·녹음·채팅을 지속되는 회의 창에 연결.
   가짜 녹음/참여 표시·지원하지 않는 API·고정 회의 번호 제거.
   미구현 성문 자동 매칭·메일 인증은 지원 여부를 명시하고 허위 완료를 없앰.
4. 운영: Windows 시작 경로에도 보존기간 삭제와 성문 폐기 실행기를 연결.
5. 사용자 시나리오: 가입/초대 → 회의/개별 동의 → 통화/녹음 → 후보 검토 →
   칸반/기여도 → 실패 복구/삭제. 키보드·좁은 창·오류 상태도 직접 확인.
6. 회귀 검사: 백엔드/프런트 전체 테스트, 타입·린트·빌드, 생성물 일치,
   화면 스모크와 실제 MediaRecorder → FFmpeg 경로.

## 구현 기준

- 생체 정보 기능을 완성한 것처럼 보이게 하는 FFT 등록을 중단합니다.
  멀티트랙의 발언자 구분은 각자의 트랙을 근거로 합니다.
- 채팅은 기여도와 AI 회의 근거로 자동 변환하지 않습니다.
- 원본/성문 삭제·보관 거부·미응답은 서로 구분합니다.
- 기존 장치 코드의 수명 관리를 React에 복제하지 않습니다.
- 사용자가 누르지 않은 동의·삭제·업무 등록은 만들지 않습니다.
- 커밋·푸시·배포는 하지 않습니다.

## 추가로 확인하고 고친 사용자 문제

- 선택 동의는 기본 미선택. 기존에 저장한 선택은 유지하며, 미지원 성문 기능을 명시합니다.
- 회의 창이 작아져도 배경 조작을 막지 않고 장치 프레임을 유지합니다. 다른 프로젝트에서 다시 열어도 진행 중 창을 우선합니다.
- 내장 장치 화면의 중복 메뉴를 숨기고 링크는 별도 창으로 열어 녹음 화면이 덮어써지는 일을 줄였습니다.
- 마이크 권한 응답이나 AudioContext가 늦게 와도 닫힌 화면에서 장치를 다시 켜지 않습니다.
- 설정 창을 닫으면 호출 버튼으로 돌아오고, 테마 버튼과 설정의 테마 선택이 같은 상태를 읽습니다.
- '전체 담당자' 선택을 빈 값으로 잃지 않도록 선택 UI 내부 값을 구분했습니다. 실제 필터 선택·복귀를 검사합니다.
- 후보의 등록/거절 선택과 최종 서버 저장이 별도임을 화면에서 안내합니다. 실제 최종 승인 후 TASK-5의 담당자·마감·근거를 확인했습니다.
- 원본 녹음 두 파일은 디스크에 보존하면서 Git 추적만 제외했습니다. 앞으로 녹음·임시 청크가 추가되지 않게 무시 규칙을 보완했습니다. 이전 커밋 기록은 변경하지 않았습니다.
- GPU 의존성 충돌을 해소했습니다. torch/torchaudio 2.11 CUDA 12.8, torchvision 0.26, TorchCodec 0.17의 import와 RTX 4090 계산 및 pip check가 통과했습니다. Docker 설정도 같은 조합으로 맞췄으며 컨테이너 실행은 확인하지 않았습니다.

## 검증의 범위

임시 DB와 합성 음성으로 검사했습니다. 실제 사용자 자료는 읽어 내보내거나 초기화하지 않았습니다.
실제 Google 계정 왕복, 운영 OAuth 자격 증명, 외부 NAT/TURN, 장시간 다중 기기 녹음, 실제 ASR/LLM 모델 추론, Docker GPU 실행은 별도 검증이 필요합니다.
685개 추적 파일의 목록 검토와 주요 위험 파일·사용자 흐름 집중 검증을 조합했습니다. 모든 입력·기기·외부 서비스 상태에서 결함이 없다는 뜻은 아닙니다.

GPU 조합은 [PyTorch 공식 설치 표](https://pytorch.org/get-started/previous-versions/)와 [TorchCodec 호환 표](https://github.com/meta-pytorch/torchcodec)를 기준으로 골랐습니다.
