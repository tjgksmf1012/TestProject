# 22 · 리디자인 「계측기」 — Vite SPA 전환

2026-08-18. 팀이 준 리디자인 패키지(`design/redesign/`)를 그대로 실행한
기록입니다. 패키지의 진단은 "지난 개편은 리스킨이었다 — 색만 바뀌고
배치가 그대로였다"였고, 처방은 **배치부터 다시**였습니다.

## 무엇이 어떻게 바뀌었나

| | 전 | 후 |
|---|---|---|
| 스택 | esbuild MPA (13개 html) | Vite + React SPA (`webapp/`, `/app` 마운트) + 기존 MPA 병행 |
| 스크롤 | 설정 4.6화면 · 검토 3.7화면 | **전 화면 1.0화면** (1280×800, 실측) |
| 색 | 청록 브랜드 + 청록빛 회색 | 인디고("근거 있음") + 황토("측정 못 함") + 냉회색 99% |
| 검토 | 세로 한 줄 (전사→후보) | **3판** — 전사 34 · 후보 41 · 근거 25, 판끼리 연동 |
| 설정 | 카드 9개 세로 나열 | 좌 서브내비 200px + 섹션 라우팅, 위험 구역 분리 |
| 기여도 | 사람 행 180px | 행 ~96px + 하단 고정 확정 바 — 세 사람과 폼이 한 화면 |
| 칸반 | 카드 330px + 상시 버튼 4개 | 카드 ~96px, 드래그 + ⋯ 메뉴 + 숫자 키 |
| 녹음 | "녹음 생존율 테스트" + 실험 조건 노출 | "녹음" + 4단계 한 카드 + 실시간 LG 리본, 개발자 말은 `?debug=1` 패널로 |

시그니처는 **트랙 리본**입니다 — LG 30px(로비·녹음, 시간축),
MD 14px(홈, 커버리지), SM 6px(기여도, **확신도**). 채움이 기여도에
비례하면 그게 순위표라서, SM 의 채움은 확신도에 비례합니다
(`webapp/src/components/TrackRibbon.tsx` 주석과 검수 D 참조).

## 구조 결정

- **SPA 는 `/app` 아래에 삽니다.** 기존 `index.html`(녹음)과 자리가
  겹치지 않고, FastAPI 는 `_SpaStaticFiles` 로 없는 경로를 index.html 에
  돌려 React Router 가 라우팅합니다 (`api/main.py`).
- **녹음(`index.html`)·통화(`call.html`)는 SPA 밖입니다.** 장치 수명을
  React 로 옮기지 않는 결정(docs/19 §24.9)은 리디자인에서도 유지됩니다.
  패키지가 요구한 것(제목·문구·리본·한 카드 4단계)은 그 자리에서
  해결했습니다. Electron smoke(녹음 생존율)로 재검증했습니다.
- **판단은 여전히 `frontend/src/lib` 한 벌입니다.** webapp 은
  `@lib` 별칭으로 같은 파일을 import 합니다 (`webapp/vite.config.ts`).
  복사해 오면 두 벌이 되고, 두 벌이 되면 한쪽만 고쳐집니다.
- **레거시 6화면(보고서·채팅·달력·알림·활동·검색)은 라우트만 유지**(R8).
  `frontend/public/tokens.css` 의 Layer 1 팔레트를 통째로 바꿔 새 정체를
  입혔고(청록 전멸), 내비에 새로 노출하지 않았습니다.

## tokens.css 팔레트 교체와 측정

Layer 1 원시값만 바꾸고 Layer 2 의미는 그대로 두어, 레거시 화면 전부가
한 번에 갈아입었습니다. **대비 주장 스물한 개를 전부 다시 재서 주석을
갱신**했고 `backend/tests/test_design_tokens.py` 가 매번 다시 잽니다.
`--gap` 의 브라우저 픽셀 고정값(`#785539`/`#ceac8a`)은 Chromium 캔버스로
실측해 못 박았습니다 — getComputedStyle 로 읽으면 0~1 실수가 나와 틀리는
자리입니다 (AGENTS §측정 방법).

`--teal-*` 는 `--indigo-*` 로 이름까지 바꿨습니다. 인디고를 담은 토큰이
teal 이라는 이름을 달고 있으면 다음 사람이 값을 의심하지 않고 이름을
믿습니다. `guards.test.ts` 의 Layer 1 목록도 같이 갱신했습니다.

## 패키지와 다르게 한 것 (이유와 함께)

1. **`할 일으로` 를 만들지 않기 위해** 칸반 메뉴의 조사는
   `withJosa(…, '으로로')` 를 씁니다 — 패키지 프로토타입은 조사를
   붙박이로 적어 뒀습니다.
2. **"목소리 특징 저장" 동의는 빼지 않고 유지**했습니다. 패키지는 "쓰는
   코드가 없다"고 권고했지만 실제로는 성문 매칭(`speaker_source:
   voiceprint`)과 삭제 요청권(`/me/data`)이 이 동의를 씁니다 — 패키지의
   오진입니다.
3. **레거시 화면의 청록 원시값 이름(`--teal-*`)을 남기지 않았습니다**
   (위 참조). 패키지는 이름까지는 말하지 않았습니다.

## 2차 검수 (수정 지시서 v2) — P0 반영

같은 날 2차 검수가 왔고, P0 두 건을 반영했습니다. P1(F3~F5)·P2(F6~F13)는
**지시대로 아직 손대지 않았습니다** — P0 결과를 보고한 뒤 진행합니다.

- **F1 — 기여도 레인이 순위 막대그래프였다.** ① 채움을 잉크색 →
  인디고(`--ribbon-known`, 다크는 지시서 지정값 `#6F5CE8`)로. ② 사선을
  2px/6px 주기로 굵게 — 리본을 SVG 에서 div + `repeating-linear-gradient`
  로 다시 썼습니다(뻗은 viewBox 는 45°를 거짓으로 만듭니다). ③ 카드마다
  자기 눈금 0/25/50/75/100 (A안 — 사람별 개별 카드 + 간격). ④ 확정
  입력란을 **비우고** placeholder 를 구간(`32~52% (시스템 추정)`)으로,
  모든 칸이 채워져야 확정 활성. "시스템 42.2" 단일 점수 표시는 없앴습니다.
  기존 불변식(시스템 값과 다르면 사유 필수 — 서버도 같은 규칙)은
  그대로라, 값을 적으면 그 행에 사유 칸이 펼쳐집니다.
- **F2 — 셸이 두 개였다.** 녹음·통화가 SPA 레일(72px) + 컨텍스트
  바(56px, 회의 제목 + 진행 상태)를 씁니다 — `app.css` 의 「SPA 셸 미러」
  절, 마크업은 두 페이지가 답니다. 옛 `#tabs` 내비는 이 두 페이지에서
  걷어냈고, guards 의 "막다른 길 금지" 가드는 `#sparail` 도 내비로
  셉니다(요구는 그대로, 찾는 자리만 갱신). 통화는 참가자를 타일
  그리드로, 하단 고정 바에 마이크 토글 · 녹음 · 나가기.
- 레거시 녹음 리본도 같은 문법: `tokens.css` 에 `--lane-known`
  (라이트 `var(--primary)` · 다크 `#6f5ce8`) 추가.

## 텍스트 최소화 리모델링 — 「계기판 문법」 (2026-08-18)

"글자가 너무 많아 지저분하다" 는 지적을 받고, 시장 제품·표준을 조사한
뒤 다섯 화면을 다시 썼습니다. **조사와 근거 전문은
`design/redesign/06-텍스트-최소화-조사.md`** — 여기에는 결과만 적습니다.

### 처방 네 줄

1. **같은 말은 한 번만** — 항목마다 반복되던 안내는 그릇으로 올립니다
   (열 머리말·헤더).
2. **값은 크게, 뜻은 작게** — 값 28px 고정폭 / 라벨 11px (`Stat`).
3. **이유는 부르면 온다** — 문장을 지우지 않고 `?` 한 겹 아래로 (`Why`).
   요약하지 않고 **원문 그대로** 넣습니다.
4. **빈 칸이 문장을 대신한다** — 회의→업무→코드 사슬을 그리고 안 이어진
   고리를 비워 둡니다 (`Chain`). 비활성 사유는 조건 칩 (`Conditions`).

새 컴포넌트 넷은 `webapp/src/components/{Stat,Why,Chain,Conditions}.tsx`,
스타일은 `app.css` 「계기판 문법」 절.

### 잰 값 (1280×800, 라이트/다크 동일)

| 화면 | 글자 전→후 | 설명 문장 전→후 | `scrollHeight` |
|---|---:|---:|---:|
| 홈 | 185 → 164 | 1 → 0 | 800 |
| 칸반 | 271 → 169 | 4 → 0 | 800 |
| 기여도 | 423 → 260 | 5 → 2 | 800 |
| 검토 (발화 원문 제외) | 330 → 240 | 7 → 1 | 800 |
| 로비 | 257 → 205 | 10 → 5 | 800 |
| **합 (껍데기만)** | **1,466 → 1,038 (−29%)** | **27 → 8 (−70%)** | — |

검토 화면 전체는 878 → 756 자입니다. 남은 것의 대부분이 **회의 발화
원문**이라 그렇습니다 — 껍데기가 아니라 읽으러 온 콘텐츠입니다.

### 실측으로 확인한 것

- **대비** — `.stat__label`·`.chain__label`·`.why`·`.cond--met` 는 처음에
  `--c-ink-faint`(3.28:1)로 만들었다가 본문 하한 4.5:1 미달로 잡혀
  `--c-ink-muted` 로 바꿨습니다 (라이트 6.18/6.18/5.51, 다크
  6.73/6.73/5.55). ⚠️ **뜻을 나르는 라벨을 장식색으로 쓰면 안 됩니다.**
- **`Why` 는 WCAG 1.4.13 세 조건을 다 지킵니다** — ESC 로 닫히고
  (dismissible), 내용 위로 옮겨도 안 사라지고(hoverable), 2.5초 뒤에도
  떠 있습니다(persistent). 키보드로도 열립니다. 보이는 크기는 18px 이지만
  `::after { inset: -13px }` 로 실제 표적은 44px 입니다.
- **`aria-disabled` 버튼** — 막힌 카드를 눌러도 승인되지 않고 첫 빈 칸
  (SELECT)으로 포커스가 갑니다. 충족된 카드는 눌리면 `등록 표시됨`.
  ⚠️ Playwright 는 `aria-disabled` 를 "비활성" 으로 보고 클릭을 거부합니다 —
  **도구가 틀린 것**이라 `force: true` 로 다시 쟀습니다(사람은 누를 수
  있습니다).
- **조건 칩이 실제 입력값과 맞는가** — 눈으로는 셋째 카드의 `마감` 칩이
  빈 원으로 보였는데, 재 보니 `● ● ●` 에 버튼도 활성이었습니다.
  **눈이 틀리고 잰 것이 맞았습니다.**
- **되풀이 문장 0건** (10자 이상이 한 화면에 두 번 이상, SPA 열두 화면).
  ⚠️ 이 0건은 되풀이를 **심어서 검사가 잡는 것을 본 뒤**에 적었습니다
  (심은 뒤 `3× 아직 아무도 참가하지 않았습니다`, 되돌린 뒤 0건).
- **JetBrains Mono 의 0 은 가운데 점이 있습니다.** 28px 축소 캡처에서
  취소선처럼 보여 결함으로 적을 뻔했고, 5배로 확대해 보니 폰트였습니다.

### 이번에 잡은 결함 — 로비가 같은 사실을 네 번 말했다

헤더 meta(`room.message`) · 본문 `p.muted` · 본문 알림(blockers) · 우측
동의 패널이 모두 "아직 아무도 / 아직 동의 안 함" 을 말했고, **앞의 둘은
글자까지 같았습니다.** 본문 둘을 걷고, 동의 사유는 그 사유가 막는
**버튼 옆**으로 옮겼습니다(`Conditions` + `Why`, GOV.UK 권고). 이름은
팝오버 안에 원문 그대로 남습니다.
