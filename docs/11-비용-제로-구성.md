[`03-시스템-아키텍처.md`](03-시스템-아키텍처.md)와 제안서 9장이 MinIO를 파일 저장소로 잡고 있는데,

- 2025년 12월 유지보수 모드 → **2026년 4월 25일 저장소 아카이브(읽기 전용)**
- 신규 릴리스 없음, 패치 검토 없음, **공식 커뮤니티 바이너리 배포 중단**

- 기존 배포본은 계속 동작하지만 보안 패치가 없습니다.

([Storm Developments](https://stormdevelopments.ca/blog/minio-s-community-edition-is-archived-what-still-runs-in-2026/),
[min.io 블로그](https://www.min.io/blog/from-open-source-to-free-and-open-source-minio-is-now-fully-licensed-under-gnu-agplv3))

**대안 (비용 0원 순서대로)**

| 옵션 | 평가 |
|---|---|
| **로컬 파일시스템 + DB에 경로 저장** | ⭐ **졸업작품에는 이게 정답** |
| Garage (Rust, S3 호환, 활발히 유지보수) | S3 API가 꼭 필요하면 |
| SeaweedFS (Apache 2.0) | 위와 같음 |
| ~~AWS S3~~ | ❌ 유료 |

**솔직히 말하면 S3 호환 오브젝트 스토리지 자체가 이 프로젝트엔 과설계입니다.**
회의 오디오 파일 몇백 개를 저장하는 데 분산 오브젝트 스토어가 필요하지 않습니다.

```python
# 이 정도면 충분합니다
STORAGE_ROOT = Path("/var/teamflow/audio")   # 별도 볼륨 + 별도 암호화
path = STORAGE_ROOT / str(meeting_id) / f"{track_id}.opus"
# DB(audio_assets)에는 상대 경로만 저장
```

[`06-데이터-모델.md`](06-데이터-모델.md)의 `audio_assets.storage_key`는 그대로 쓰면 됩니다.
"MinIO 객체 키"를 "파일 경로"로 해석만 바꾸면 되고, 나중에 오브젝트 스토리지로 옮겨도
스키마가 안 바뀝니다.

⚠️ 단, [`07-법적-윤리-요구사항.md`](07-법적-윤리-요구사항.md)의 **분리 보관 요구는 유지**하세요.
파일시스템을 쓰더라도 **별도 디렉터리 + 별도 암호화 키 + 별도 접근 권한**입니다.

### ⚠️ 3. 멀티트랙 녹음에는 HTTPS가 필수입니다 (숨은 요구사항)

[`04-회의-처리-파이프라인.md`](04-회의-처리-파이프라인.md)의 멀티트랙 제안에 함정이 있습니다.

**브라우저의 `getUserMedia()`(마이크 접근)는 보안 컨텍스트에서만 동작합니다.**
`localhost`는 예외지만, **팀원 휴대폰이 개발 PC에 접속할 때는 `http://192.168.x.x`** 가 되고,
이건 보안 컨텍스트가 아니라서 **마이크 권한 요청 자체가 뜨지 않습니다.**

즉 멀티트랙 데모를 하려면 HTTPS가 반드시 필요합니다. 그런데 **무료로 됩니다.**

**해결: Cloudflare Tunnel (무료)**

```bash
cloudflared tunnel --url http://localhost:3000
# → https://random-words-here.trycloudflare.com 출력
# 인증서 자동, 계정 불필요, 포트포워딩 불필요, 도메인 불필요
```

- 무료 플랜에서 로컬 서비스를 공개 호스트명으로 노출 가능. **인증서 설정 0**.
- `trycloudflare.com` 랜덤 서브도메인은 **계정 없이도** 즉시 발급됩니다.
- 공유기 포트포워딩, 고정 IP, 도메인 구입이 전부 불필요합니다.

([Cloudflare Quick Tunnels 문서](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/do-more-with-tunnels/trycloudflare/))

대안: ngrok 무료 티어(세션마다 URL 변경, 동시 연결 제한), `mkcert` 자체 서명(폰에 루트 인증서를
설치해야 해서 시연에 부적합).

> 💡 **0주차 환경 구축에 이 항목을 넣으세요.** 폰 2대로 마이크 권한이 뜨는지 확인.
> 여기서 막히면 멀티트랙 설계 전체가 무너집니다.
