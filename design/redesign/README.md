## 에이전트에게 넘기는 법

프로젝트 루트에 이 폴더를 통째로 복사하고, `AGENTS.md`를 루트로 올리세요.

```bash
cp -r teamflow-redesign/ /path/to/teamflow/design/
cp teamflow-redesign/AGENTS.md /path/to/teamflow/AGENTS.md
```

Claude Code를 쓴다면 `CLAUDE.md`에 한 줄만:

```markdown
@AGENTS.md
```

그리고 이렇게 시작하세요:

> `design/00-진단.md`와 `AGENTS.md`를 먼저 읽어. 지난 리디자인이 왜 실패했는지
> 적혀 있다. 그 실패를 반복하지 마라. AGENTS.md의 절대 규칙 R1~R8을 지키고,
> 작업 순서대로 진행해. 각 단계가 끝날 때마다 1280×800으로 스크린샷을 찍어서
> 스크롤 예산(R2)을 실제로 측정해라.

## 이 패키지의 한 줄 요약

지난번 실패의 원인은 **"예쁘게 바꿔줘"라는 요구가 스타일 요구로 해석됐기 때문**입니다.
에이전트는 색·폰트·radius를 바꾸고 완료를 보고했고, 레이아웃은 손대지 않았습니다.
레이아웃 재구성은 diff가 크고 회귀 위험이 있어서, **명시적으로 요구하지 않으면
에이전트가 하지 않습니다.**

그래서 `AGENTS.md`에는 "예쁘게"라는 말이 한 번도 나오지 않습니다.
대신 **화면별 최대 스크롤 예산**, **금지된 패턴**, **반드시 존재해야 하는 구조**로
씌어 있습니다. 통과 여부를 눈이 아니라 자로 재게 만드는 것이 핵심입니다.
