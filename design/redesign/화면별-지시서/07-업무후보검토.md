# 업무 후보 검토 — 3.7 화면 → 1.0 화면

**현재**: 2971px. 그리고 화면의 목적이 뒤집혀 있습니다.

---

## 무엇이 문제인가

이 화면의 **단 하나의 목적은 후보를 승인/거절하는 것**입니다. 그런데 지금은:

```
  0px  발언 통계 (제안 1 · 동의 1 · 반대 의견 1 · …)
 150px 눈에 띈 것 (반복 논의 / 주제 이탈)
 400px 타임라인 — 전사 20여 발언 전문
       ┊
1100px ─────── 여기까지 스크롤해야 ───────
1100px 필터 탭 [전체 3][검토 필요 3][등록 0][거절 0]
1150px 후보 카드 ①  배포 방식 결정      34%
1300px 후보 카드 ②  회원가입 화면 작업   71%
1450px 후보 카드 ③  로그인 API 구현     92%
2900px [제출]
```

**주 작업에 도달하려면 1100px을 스크롤합니다.**

전사는 근거를 확인할 때 **참조하는 것**이지 매번 처음부터 읽는 것이 아닙니다.
좌우로 나뉘었어야 할 것이 상하로 쌓였습니다.

부차적 문제:
- 근거 번호 `근거 #5`가 카드 **우측 끝**에 작게 있어서, 승인 판단의 핵심 정보인데
  눈에 안 들어옵니다.
- 확신도 알약(`34%` `71%` `92%`)이 카드 우상단에 크게 있어서 **가장 먼저 눈에 띕니다.**
  연구상 잘못 보정된 확신도를 단독으로 강조하면 과의존을 유발합니다.
  이 화면에서 제일 중요한 건 확신도가 아니라 **근거**입니다.
- AI가 만든 것과 사람이 정하는 것이 **시각적으로 구분되지 않습니다.**
  사용자의 원래 질문 — "AI가 뽑고 사람이 승인한다가 화면만 보고 전달되나?" —
  에 대한 현재 답은 **아니오**입니다.

## 새 구조 — 3판

```
┌──────┬─────────────────────────────────────────────────────────────┐
│      │ 1주차 정기회의 · 업무 후보 3건        [3건 모두 처리하고 제출]│
│ 레일 ├──────────────────┬──────────────────────┬───────────────────┤
│      │ 회의 내용         │ 후보 (검토 필요 3)    │ 근거              │
│      │ ───────────────  │ ────────────────────  │ ────────────────  │
│      │ ▸ 요약           │ ┌──────────────────┐ │ 발화 #1  0:01     │
│      │ ▸ 눈에 띈 것 2건  │ │ ① 로그인 API 구현 │ │ 김민수 · 결정      │
│      │                  │ │   김민수 · 09-11   │ │ "로그인 API는     │
│      │ 0:01 김민수 ●    │ │   근거 #1 #3      │ │  민수가 금요일까지 │
│      │  로그인 API는…   │ │   [등록][나중][거절]│ │  만들기로 하죠"    │
│      │                  │ └──────────────────┘ │                   │
│      │ 0:09 이하늘      │ ┌──────────────────┐ │ 발화 #3  0:16     │
│      │  네 저는 회원가입…│ │ ② 회원가입 화면   │ │ 김민수 · 의견      │
│      │                  │ │   담당자 미지정 ⚠ │ │ "인증 방식은 JWT로 │
│      │ 0:16 김민수 ●    │ │   근거 #2         │ │  가는 게 좋겠습니다"│
│      │  인증 방식은 JWT…│ │   [등록][나중][거절]│ │                   │
│      │       ↑          │ └──────────────────┘ │                   │
│      │  근거인 발화는    │                      │  ↑ 선택된 후보의   │
│      │  인디고 점 표시   │  ↑ 이 판만 스크롤     │    근거만 표시     │
│      │  (이 판만 스크롤) │                      │                   │
│      │      34%          │        41%           │       25%         │
└──────┴──────────────────┴──────────────────────┴───────────────────┘
```

- **페이지는 스크롤하지 않습니다.** 세 판이 각자 `overflow-y: auto`.
- 좌: 회의 내용 (요약·눈에 띈 것은 접힌 상태로 상단, 전사는 그 아래)
- 중: 후보 카드 — **주 작업**
- 우: 선택된 후보의 근거 발화 (없으면 "후보를 고르면 근거가 여기 나옵니다")

### 판 사이 연결 (이게 이 화면의 핵심 가치)

- 후보 카드를 선택 → 우측 판에 근거 발화 표시 + **좌측 전사가 해당 발화로 스크롤**
- 근거 칩 `#1` 클릭 → 같은 동작
- 좌측 전사에서 근거로 쓰인 발화에는 인디고 점 표시
- 1279px 이하에서는 우측 판을 **드로어**로 전환 (좌 2판만 유지)

## 후보 카드 재설계

**"AI가 만들었다 / 사람이 정한다"를 형태로 구분합니다.**

```
┌────────────────────────────────────────────────────┐
│ AI 초안                              확신 92%  ← 12px 모노, 흐림
│                                                    │
│ 로그인 API 구현                       ← 20px, 잉크  │
│ 근거 #1 #3                            ← 인디고 칩   │
│ ┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈  ← 점선: 여기부터 사람의 몫
│ 담당자 [ 김민수  ▾ ]   마감 [ 2026-09-11 ]         │
│                                                    │
│ [ 업무로 등록 ]  나중에  거절                       │
└────────────────────────────────────────────────────┘
```

규칙:
- **점선 위 = AI가 뽑은 것.** 잉크 + 인디고 근거 칩. 편집 불가.
- **점선 아래 = 사람이 정하는 것.** 입력 컨트롤만.
- 확신도는 **우상단 12px 모노, `--c-ink-faint`** 로 축소. 알약 배경 제거.
  숫자를 없애진 않되 **근거보다 작게** 합니다.
- 근거 칩은 인디고. **근거가 없으면 칩 대신** `⚠ 근거 없음 — 등록할 수 없습니다`
  (황토) 를 표시하고 `업무로 등록`을 영구 비활성.
- 담당자/마감 미지정이면 등록 버튼 비활성 + 비활성 사유를 버튼 바로 위에.

### 정렬
확신도 낮은 것부터 위 (현재 동작 유지). 이건 "못 믿을 것부터 사람이 본다"는
의미라서 옳습니다.

## 좌측 판 — 회의 내용

현재 상단에 있던 `발언 통계` `눈에 띈 것`은 **접힌 disclosure 2개**로 축소:

```
▸ 요약 · 다음 안건 2 · 답 안 난 것 1
▸ 눈에 띈 것 2건 — 반복 논의 · 주제 이탈
─────────────────────────────────────
0:01  김민수 · 결정                    ●
      로그인 API는 민수가 금요일까지…

0:09  이하늘 · 일정 약속
      네 저는 회원가입 화면을 맡을게요
```

- 시각·이름·발화 유형은 12px, 발화 본문은 14px
- 시각은 모노
- 근거로 쓰인 발화 우측에 인디고 점
- **`무슨 말이 오갔나`처럼 사람별 통계로 읽힐 수 있는 블록은 기본 접힘.**
  발언 수를 나란히 보여주면 그게 곧 순위표입니다 (불변식 R6-1).
