# 기여도 — 2.1 화면 → 1.0 화면

**현재**: 1718px. 이번 리디자인에서 **유일하게 실질적으로 개선된 화면**입니다.
흙빛 막대를 점 표시로 바꾼 것은 옳은 변경이니 유지하고 다듬습니다.

---

## 유지할 것 (건드리지 마세요)

- 구간 표시 (`32~52%`), 단일 점수 없음
- 점 표시 dot plot + `모르는 폭 20%p · 점 하나가 4%p` 설명
- 결측이 빨강이 아니라 흙빛
- 이름순 고정, 순위 없음, 막대그래프 없음
- 상단 경고문 — 특히 이 문장은 그대로:
  > 팀 전원의 신뢰도가 낮습니다. 이 수치로 서로를 비교하지 마세요 —
  > 연결되지 않은 데이터가 무엇인지 먼저 확인해야 합니다.
- 하단 팀 확정 폼 + 사유 필수

---

## 무엇이 문제인가

1. **세 사람을 동시에 볼 수 없습니다.** 경고 → 사람1 → 사람2 → 사람3 → 확정폼이
   세로로 쌓여서, 확정 폼에 도달할 때쯤엔 위의 값이 안 보입니다.
   확정하려면 스크롤을 오르내려야 합니다.
2. 사람 행 하나가 **180px**입니다. 정보량 대비 과합니다.
3. 점 표시가 좋아졌지만 **구간과 시각적으로 연결돼 있지 않습니다.**
   `32~52%`와 점들이 별개 요소로 놓여 있습니다.

## 리본과 구간의 통합

지금은 `32~52%`와 점 표시가 따로 놓여 있습니다. 하나로 붙입니다.

```
김민수     32~52%    ▓▓▓▓▓▓▓▓░░░░░░
                     └───┬──┘└──┬──┘
                      아는 것   모르는 폭 20%p
                    (잉크색)   (황토색)
```

- 리본 SM(6px) 사용. 채워진 부분 = 확신, 황토 부분 = 불확실
- 리본 총 폭은 **모든 사람이 동일** (사람마다 다르면 그게 곧 막대그래프 = 순위표)
- **절대 금지**: 세 사람의 리본을 같은 축에 정렬해 길이 비교가 가능하게 만들기.
  각 리본은 자기 행 안에서 "이 사람에 대해 우리가 얼마나 아는가"만 표현합니다.

> ⚠ 불변식 검사: 리본의 **채워진 길이가 기여도 값에 비례하면 안 됩니다.**
> 채워진 길이는 **확신도**에 비례합니다. 기여도가 높은 사람이 아니라
> 우리가 잘 아는 사람의 리본이 깁니다. 이걸 헷갈리면 순위표가 됩니다.

## 결측 표시

박지원의 케이스(`회의 1건 중 1건이 끊겼습니다`)는 지금 문구가 정확합니다. 유지.

```
⚠ 회의 기여를 측정하지 못했습니다              ← --c-unknown, 아이콘 동반
  녹음 1건 중 1건이 끊겼습니다. 0으로 계산하지 않고
  나머지 활동으로 추정했습니다.
```
- 색은 `--c-unknown`. **빨강 금지.**
- 아이콘 + 텍스트 라벨 동반 (색만으로 전달 금지)
- 상세는 `▸ 신뢰도 사유`로 접기

## 확정 폼 — 하단 고정 바

```
┌─────────────────────────────────────────────────────────────┐
│ 참고값입니다. 최종 기여도는 팀이 합의해 확정합니다.          │
│                                                             │
│  김민수  시스템 41.7 → [ 41.7 ]                             │
│  박지원  시스템 24.9 → [ 24.9 ]                             │
│  이하늘  시스템 33.0 → [ 33.0 ]                             │
│                                          [ 이 값으로 확정 ]  │
└─────────────────────────────────────────────────────────────┘
```
- 입력값이 시스템 값과 다르면 **그 행에만** 사유 입력칸이 펼쳐집니다
  (지금처럼 3개를 항상 펼쳐두지 마세요 — 이것만으로 400px 절약)
- 사유 없이 다른 값이면 확정 비활성 + `사유 없는 조정은 근거 없는 점수와 같습니다`
- 시스템 값은 무채색(참고), 확정 버튼은 인디고(행동)
- 합계가 100이 아니어도 막지 마세요. 경고만 표시 — 팀의 결정이 우선입니다
